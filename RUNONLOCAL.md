# How to Run AGROROVER on Local :

1. **[Install MongoDB](https://www.mongodb.com/try/download/compass)**
   
2. **Clone Projects from GitHub**
   
    [Agrorover](https://github.com/athanginfotech/agrorover.com)

    [Agrorover Microservices](https://github.com/athanginfotech/agrorover-microservices)

    [Agrorover Websocket](https://github.com/athanginfotech/agrorover-websocket)
    - Use above links to clone projects. 
   - Run : `git clone [https Link]`

3. **Open project in IDE**

4. **Install Dependencies**
   - Run : `npm i`

5. **Run project**
   - Run : `npm run dev`

6. **Follow these steps from 2 to 5 for all three repos (agrorover.com, agrorover-microservices, agrorover-websocket)**

7. **Add secret key in env.development file in agrorover-microservices**
